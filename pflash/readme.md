AI generated CP/M firmware updater for the PICO9918. 

No warranty. Use at your own risk. That being said, you can fix any bad software flash using the USB update method.

Software updating was added in firmware v1.0.1, so if you have an older firmware then you'll need to USB update.

I just generated this for my own use and I don't plan on updating it, so feel free to improve it.

It defaults to the NABU PC VDP port A0 but if you change the VDP port, it should work on any computer that runs Z80 CP/M.

I've only tested it on NABU PC.

The screen is blank while flashing but it is outputing text to CP/M, so if you redirect the IO to a terminal, you will see the blocks counting up and any other, hopefully not error messages that appear.

Download updated .uf2 firmware files from https://github.com/visrealm/pico9918/ and rename them to a short name like 111.uf2 for easy typing.

This is a third party tool, so don't ask visrealm for support.
